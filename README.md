# Memoria AI 🧠✨
### Palliative & Memory Care Companion with Compassionate Voice AI

Memoria AI is a compassionate, accessible web application designed to support individuals living with memory loss and early-to-mid stage dementia, while providing peace of mind and live telemetry oversight for caregivers.

---

## 🌟 Key Features

### 1. Patient Reassurance & Voice Assistant
- **Empathetic AI Companion**: Built with comforting orientation rules — never argues with confusion, gently reassures time, place, and family connections.
- **Natural Voice Interaction**: Support for ElevenLabs high-quality compassionate voice streaming and free browser speech synthesis.
- **Familiar Memory Anchors**: Instant photo cards and comforting voice notes from loved ones (e.g. daughter Sarah).
- **One-Tap Emergency Direct Call**: Prominent, accessible emergency button connecting immediately to designated family caregivers.

### 2. Brain Gym (Cognitive Care)
- **Gentle 4×4 Sudoku**: Calm, low-pressure logic puzzles with accessible hints and quadrant layouts.
- **Morning Word Recall**: Everyday memory association games with visual cues, tactile letter tiles, and encouraging feedback.
- **Memory Pair Match**: Fluid 3D card-flip exercises celebrating familiar everyday items without countdowns or stress.
- **Voice-Operated Gameplay**: Patients can play completely hands-free by speaking answers aloud (e.g., *"Fill two"*, *"Letter E"*).

### 3. Caregiver Dashboard
- **Live Health & GPS Telemetry**: Real-time patient coordinates, device battery status, connection health, and observed mood.
- **7-Day Cognitive Trend Analytics**: Interactive trend charts showing cognitive engagement and daily routine compliance.
- **Medication Schedule Manager**: Add and manage prescriptions with exact times, dosages, and frequencies.
- **Photo Memory Vault**: Secure gallery to upload familiar faces and memories directly to the device.

---

## 🎨 UI/UX Design System (UI/UX Pro Max)
- **Senior-First Accessibility**: High-contrast ratios (WCAG AAA compliant), large tactile touch targets (min 52px), and generous spacing.
- **Typography Scale**: **Plus Jakarta Sans** for crisp, modern headers, combined with **Atkinson Hyperlegible Next** for maximum legibility.
- **Color Harmony**: Healing sage emerald (`#00714e`) and warm terracotta (`#cc4900`) on calming cream/slate surfaces.
- **Fluid Micro-Interactions**: Ambient glassmorphism, responsive radar mic pulse, 3D card flips, and cheerful reward confetti bursts.

## 🚀 Getting Started

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Bashir-Abiyev/Memoria-ai.git
   ```
2. Open `index.html` directly in any modern browser (Chrome, Edge, Safari, Firefox).
3. (Optional) Open **Settings** (gear icon) to configure:
   - Google AI Studio Gemini API Key
   - ElevenLabs API Key for custom synthesized voices
   - Custom patient & caregiver names and telephone numbers

---

## 🔒 Privacy & Safety
- All memory vault photos and personal routine data are stored locally in the browser's `localStorage` and never transmitted to external databases without explicit consent.
- `.env` files and secret keys are excluded via `.gitignore`.
